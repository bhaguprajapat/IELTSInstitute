# IELTS Institute Website

A modern, responsive single-page React.js application for an IELTS Institute.  
The project is built using **React + Vite** and styled with **Bootstrap 5** for a professional and mobile-friendly UI.

---

## 🚀 Features
- **Navbar**: Logo + navigation menu
- **Hero Section**: Headline, subtext, CTA button, and banner image
- **Features Section**: 3–4 feature cards (Speaking Practice, Mock Tests, AI Band Score, Dashboard)
- **Student Testimonials**: Responsive cards with student reviews
- **Footer**: Institute info and contact details
- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop

---

## 🛠️ Tech Stack
- **React.js (Vite)** – Frontend framework
- **Bootstrap 5 / React-Bootstrap** – UI components & responsive grid system
- **JavaScript (ES6+)**
- **Node.js & npm** – Development environment
